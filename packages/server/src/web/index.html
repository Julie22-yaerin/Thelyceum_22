01 — the panel
Three switches. One pool of tools your agents can't trip on their own.
brake
stops the action
Scans a planned action before it runs — data exfiltration, destructive commands, credential leaks. Blocks in under 1000ms, every call, on the hot path.
$ brake scan "rm -rf /var/db/production"
redteam
stops the argument
Challenges a one-sided conclusion before it ships — unsupported claims, confirmation bias, missing counter-evidence. Nine flaw classes, warn or block.
$ redteam challenge "this migration is safe"
thrift
stops the bill
Deduplicates and compresses tool output before it re-enters context — lossless first, truncation only as a last resort. Trips a runaway loop at 2 repeats.
$ thrift measure . --passes 5
